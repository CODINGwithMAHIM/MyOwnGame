# MyOwnGame
🎮 This is a simple web-based game built using HTML, CSS, and JavaScript. The game focuses on basic interactivity, animations, and logic implementation to provide an engaging experience. It runs directly in the browser and does not require any installation. 

---

## 🚀 Features
- Built using pure **HTML**, **CSS**, and **JavaScript**.
- Simple and interactive gameplay.
- Lightweight and runs directly in any modern web browser.
- Beginner-friendly code structure.

---

## 🛠️ Technologies Used
- **HTML5** – For structuring the game.
- **CSS3** – For styling and layout.
- **JavaScript (Vanilla)** – For game logic and interactivity.

---
---

## ▶️ How to Play
1. Open `index.html` in your browser.
2. Follow the on-screen instructions to play.
3. Enjoy!
